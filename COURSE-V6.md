# MathsReady V6 small-step fluency course

Official progression rule: **100% correct + full set at or under the Standard Mastery Time (SMT)**.

## Addition
+1 → +2 → +3 → mixed +1..3 → +4 → +5 → mixed +1..5 → +6 → +7 → mixed +1..7 → +8 → +9 → all single-digit facts → bridge through 10 → +10 → 2-digit + 1-digit (no bridge) → bridge → within 50 → within 100 → 2-digit + 2-digit (no exchange) → exchange.

## Subtraction
−1 → −2 → −3 → mixed −1..3 → −4 → −5 → mixed −1..5 → −6 → −7 → mixed −1..7 → −8 → −9 → all single-digit subtraction facts → bridge back through 10 → −10 → 2-digit − 1-digit (no exchange) → exchange → within 50 → within 100 → 2-digit − 2-digit (no exchange) → exchange.

## Multiplication
2× → 10× → 5× → mixed 2/5/10 → 3× → 4× → mixed checkpoint → 6× → 7× → 8× → 9× → mixed 2–10 → 11× → 12× → mixed 2–12.

## Division
Division mirrors the multiplication dependencies: ÷2 → ÷10 → ÷5 → mixed → ÷3 → ÷4 → mixed → ÷6 → ÷7 → ÷8 → ÷9 → mixed 2–10 → ÷11 → ÷12 → mixed 2–12.

## Data safety
New V6 fluency steps use new stable IDs (`add01`, `sub01`, `mul01`, `div01`, etc.). Existing older progress remains in the learner record and is not overwritten.
